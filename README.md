# Meu Primeiro Projeto 🚀

Este é o meu primeiro repositório no GitHub, criado para praticar o uso de sistemas de controle de versão e hospedagem de código na nuvem.

## 💻 Sobre o Projeto
O objetivo deste projeto é organizar e versionar os arquivos de um site básico estruturado em HTML e CSS.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação das páginas e conteúdo.
- **CSS3:** Estilização, cores e layout do site.
- **Git & GitHub:** Controle de versão e hospedagem do código.

## 📂 Como visualizar o projeto
1. Faça o clone deste repositório ou baixe os arquivos em formato `.zip`.
2. Abra o arquivo `index.html` em qualquer navegador web.
